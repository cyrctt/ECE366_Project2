**# ECE366_Project2**
A MIPS assembly program using the MARS simulator to compute Fibonacci numbers, determine whether numbers are odd using repeated subtraction, and check if the nth Fibonacci number is odd.

**How to test:**
1. Open MARS and load IsFibonacciOdd.asm (or fibonacci.asm / IsOdd.asm).
2. In the Edit tab, change the number for n at the top of the file to any nonnegative integer you want to test (or change m if you are running IsOdd.asm).
3. Click Run and then Assemble to switch to the Execute tab.
4. Click Run and then Go to run the program.
5. Check the result in the Data Segment at the bottom of the Execute tab, or in the Run I/O window. For IsFibonacciOdd.asm and IsOdd.asm, 1 means odd and 0 means even.
